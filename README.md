# Nusantara-Train-Empire-v1
Nusantara Rail Empire adalah game simulasi manajemen dan pembangunan stasiun kereta api yang terinspirasi dari perkeretaapian Indonesia.  Jadilah pengelola stasiun dan bangun pusat transportasi impianmu! Atur tata letak stasiun, kembangkan berbagai fasilitas, kelola pelayanan penumpang, serta operasikan perjalanan kereta.
